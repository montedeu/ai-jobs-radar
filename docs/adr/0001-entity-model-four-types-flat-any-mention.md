# Четыре типа сущностей, плоские, упоминание без учёта роли

Сущность имеет один из четырёх типов: метод, модель, задача, датасет. Упоминанием считается любое явное появление сущности в названии или аннотации, независимо от роли (предложена, использована, взята для сравнения, отвергнута). Отношений «родитель — потомок» между сущностями нет: статья считается только за те сущности, что в ней названы. Имя сущности — устоявшееся название без уточнений языка, домена и размера; версия модели остаётся частью имени.

Решения приняты разработчиком в сессии проектирования 10 ноября 2026 по рекомендациям агента. Доводы ниже — наблюдения агента, с которыми разработчик согласился.

## Рассмотренные варианты

- **Модель как разновидность метода (три типа).** Отклонено: любая новая модель растёт с нуля, поэтому список растущих методов состоял бы из свежих релизов, а техники в нём терялись бы. Граница проведена правилом «есть имя релиза — модель».
- **Считать только используемое или предлагаемое.** Отклонено: роль — вторая классификация поверх извлечения, она добавляет ошибку модели и спорные случаи в разметке. Отброшенные упоминания нигде бы не сохранялись, и расширение потребовало бы полной переразметки.
- **Извлекать всё и помечать роль.** Отложено: на 60 аннотациях эталона метрику по ролям не измерить.
- **Иерархия сущностей (статья с QLoRA засчитывается в LoRA и PEFT).** Отложено: дерево связей — вторая ручная структура поверх словаря синонимов.

## Следствия

- «Растёт» означает «всё чаще упоминают», а не «всё чаще применяют»; ответы сервиса должны это оговаривать.
- На вопрос «растёт ли PEFT в целом» сервис отвечает только по статьям, где написано «PEFT».
- Роль добавляется позже одним полем: новый полный прогон и доразметка ролей в эталоне, сами упоминания переразмечать не нужно.
- Иерархия добавляется позже отдельной таблицей поверх канонических имён, без нового прогона и без переразметки.
- Правило «имя без уточнений» теряет уточнение уже в написании: чтобы получить сущность вроде «low-resource machine translation», нужен новый полный прогон.
