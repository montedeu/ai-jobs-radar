# ml-research-radar

Радар ML-исследований на arXiv. Термины — `GLOSSARY.md`, решения и их причины — `docs/adr/`, что осталось сделать — задачи GitHub. Срок сдачи — 30 ноября 2026.

## Категория 2: метод «Техлид»

Код пишет агент, решения и понимание принадлежат разработчику.

- Развилку с настоящими альтернативами агент выносит разработчику с рекомендацией и ждёт ответа.
- Работа идёт по задачам GitHub: одна задача — одна ветка — один PR, в описании PR `Closes #N`.
- В конце каждой недели — проверка понимания по принятым решениям (навык `understanding-check`).

## Учебный островок: запрос роста

`src/research_radar/sql/growth.sql` пишет разработчик; условие — `docs/growth-query.md`, тесты — `tests/test_growth.py`. Запись в файл агенту закрыта хуком.

- Агент пишет всё вокруг: условие, тесты, обёртку.
- Подсказки усиливаются только по просьбе разработчика: направление → понятие → разбор на похожем, но другом примере. Готовое решение и его части остаются за разработчиком.
- Ревью запроса: упавшие тесты с причиной; ошибку, которую тесты не ловят, агент показывает новым падающим тестом; улучшения — место, следствие и доказательство (`EXPLAIN ANALYZE`), исправление пишет разработчик.
- Собственное решение для проверки тестов агент держит вне репозитория и удаляет сразу после проверки.
- Помесячный ряд агент пишет после приёмки запроса роста.
- Если запрос не готов к сроку, выбор между сдвигом демо и более сильной подсказкой делает разработчик.

## Деньги

- Платное запускает разработчик: полный прогон извлечения и всё, что тратит ключи Anthropic сверх пилота на 200 аннотаций. Потолки: $20 на извлечение, $5 на агента.
- Подъём модели агента с Haiku 5.5 до Sonnet 5.5 — решение разработчика по результату набора вопросов.
- Ключи и токены живут в Secret Manager. Бесплатно шесть активных версий секретов на платёжный аккаунт, поэтому при замене старая версия отключается.

## Что сервис оговаривает в ответах

- «Растёт» означает «чаще упоминают в аннотациях».
- Иерархии сущностей нет: «PEFT» считается только по статьям, где написано «PEFT».
- Цифры качества относятся к cs.CL и к прочтению правил одним разметчиком.
- Проект независим от arXiv и им не одобрен.
